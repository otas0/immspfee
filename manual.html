1. live vs reset

类型判定行为示例
livegroup = dynamics，且不在强制重置键表写回 params，下一帧立刻用新值；高度/相位不跳回g, k, m, μ, R, C, 学习率
resetgroup = initial / numerics，或键 ∈ 强制表保留 params 后 init()，仿真状态重建h₀, x0, v0, θ0, seed, n, algo

工作台顶部「应用到模型」条会提示；dyn 行带 live 标记。调试：localStorage.physics-lab-debug-params=1 后改参有 120ms 防抖日志。

2. 现有参数

工作台内数值可任意输入（含科学计数）。电位器仅参考调节；双击旋钮恢复默认；方向键按量级步进，Home 复位。离散 algo 等为下拉。

3. 自定义键

keyeffect
a_extra / a_*累加到加速度 / 角加速度（质点类模型）
k_extra弹簧 k_eff = k + k_extra
expr_a受限表达式，结果累加到加速度
其它写入 params；模型读取同名键则直接生效

4. expr_a

expr_a = -0.2 * v
expr_a = a_extra + 0.01 * t

仅允许标识符与 + - * / % ( )。无 Math.*。场 / 冲量模型不走 expr_a，见下节。

6. 无 expr_a 时怎么改（collision / wave / heat）

collision · 一维碰撞

冲量瞬时发生，没有连续加速度项；expr_a / a_* 不会接入。直接改：

  • m1, m2 — 质量比决定碰后分配
  • v1, v2 — 初速（符号为方向）
  • e — 恢复系数（0 完全非弹，1 完全弹性）
m1=4  m2=1  v1=2  v2=0  e=0.5

wave · 横波 / 弦

离散弦场，步进是波动方程而非单点 a(t)。改：

  • c — 波速；damp — 阻尼
  • A1… 或模型内振幅 / 初形参数
  • 不要加 expr_a（不会驱动网格节点）
c=1.5  damp=0.02

heat · 热传导

一维扩散场，边界恒温。改：

  • alpha — 热扩散率（过大显式格式会炸）
  • Tleft, Tright, T0, hotspot — 边界与初温
  • N, L — 网格分辨率与长度
alpha=0.01  Tleft=100  Tright=20  hotspot=80
